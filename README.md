# Car Evaluation using Machine Learning

## About the Project

This project applies machine learning algorithms to the Car Evaluation dataset.

The aim is to predict the acceptability of a car based on its features.

## Dataset

The dataset contains information about:

- Buying price
- Maintenance cost
- Number of doors
- Number of persons
- Luggage boot size
- Safety

The target variable is the car's acceptability.

## Machine Learning Algorithms

The following algorithms were applied:

1. Decision Tree
2. K-Nearest Neighbors (KNN)
3. Random Forest

## Evaluation Metrics

The algorithms were compared using:

- Accuracy
- Precision
- Recall
- F1 Score

## Result

The performance of all three algorithms was compared and the algorithm with the highest accuracy was selected as the best-performing algorithm.

## Technologies Used

- Python
- Pandas
- Scikit-learn
